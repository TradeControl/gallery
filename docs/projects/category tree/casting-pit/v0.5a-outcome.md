# Casting Pit v0.5a outcome — Universe / Cosmos Overlay

14 September 2026

## Principal question

Can the signed-off material Universe and ordered Cosmos inhabit one distorted Casting Pit while remaining governed by visibly different laws?

**Technically yes; artistically unresolved pending human review.** v0.5a composes the two existing systems without making either one determine the other's behaviour.

## Experiment

The new sibling study is located at:

    src/casting-pit/universe-cosmos-v0.5a/

The reference studies remain at:

    src/casting-pit/physical-layer/
    src/casting-pit/information-layer/

No throat, Tree, Category Tree semantics or post-processing was added.

## Implemented model

The composition root creates:

1. one renderer, scene, camera, orbit controller and animation loop;
2. one shared parameter object;
3. one Gaussian membrane function and gradient;
4. one Universe layer using the signed-off physical environment;
5. one Cosmos layer using that membrane but omitting its standalone duplicate environment.

Universe and Cosmos register independent frame callbacks. The shared world invokes both before the orbit-control update and render. Neither layer imports, owns or calls the other.

## Environment ownership

The Universe environment supplies the visible membrane material, receiver and lights. Selecting one environment avoids coincident surfaces, duplicated receivers and doubled illumination.

The Cosmos still creates its own internal environment objects because that preserves a single factory implementation for its reference page, but `includeEnvironment: false` prevents those objects entering the combined scene. Only the network manifestation is mounted.

The shared wireframe is the Universe diagnostic mesh and is off by default.

## Shared parameters and deformation

Both factories receive the same parameter object. The membrane height and gradient therefore always describe one world.

The common depth and width sliders first update the physical membrane and molten geometry, then rebuild the manifested Cosmic geometry and route-length metrics. The logical Cosmic graph is not regenerated. Existing signals retain fractional progress when manifested distances change, as in v0.4b.

Universe's depth `5.5` and width `3.8` are the combined defaults. This preserves the physical field that governs lava. The information study's independent defaults were depth `7.1` and width `3.7`; that unavoidable difference is exposed through the live shared controls and documented in the review.

The combined surface binding defaults to `1.0`, rather than the information reference's `0.82`. Initial orbiting showed that partial interpolation toward the flat logical plane placed routes materially above steep parts of the membrane, allowing the information layer to move into the foreground as the view changed.

## Independent laws

### Universe

The physical callback retains fixed-step parcel integration, peripheral emission, packet-backed shared-rim storage, independent gate phasing, exit impulses, gravity-gradient response, drag, neighbour interactions, deposition and reconstruction-field decay.

Its visible output remains one transparent molten mesh reconstructed over the membrane. Gate geometry remains hidden.

### Cosmos

The logical network is generated solely from seeded territorial hierarchy parameters. It does not query membrane height, gradient, depth, width or distance from the pit.

Only manifestation projects the graph into the shared world. Signals advance by `signal speed × elapsed time` through cumulative 3D length sampled from the manifested rough conduit. Gravity, slope and molten state never enter that equation.

## Diagnostic layer modes

Three mode buttons call the layers' visibility methods:

- **Universe only** hides all Cosmic network and communication objects;
- **Cosmos only** hides the molten reconstruction and physical packet diagnostics;
- **Combined** shows both.

The membrane environment remains present in every mode. Hidden systems continue to update, so mode changes preserve ongoing reservoir phases, packet positions and communication progress.

## Control coexistence

The original pages were both built around unprefixed control identifiers such as `reset`, `reseed` and `seed-value`. v0.5a gives Universe controls a `u-` prefix and Cosmos controls a `c-` prefix.

The factories now accept an optional `controlPrefix`; omission retains reference-page behaviour. Cosmos additionally accepts `bindEnvironmentControls: false`, allowing the composition root to provide the shared membrane, light, exposure and diagnostic controls. This is a concrete composition requirement rather than a general UI framework.

## Library changes

`createSluiceGateLayer()` now accepts `controlPrefix` and `moltenRenderOrder`, and returns `setVisible()`.

`createCosmicCircuitryLayer()` now accepts `controlPrefix`, `bindEnvironmentControls` and `manifestationLiftScale`, and returns `setVisible()`.

All new options default to the earlier standalone behaviour. Both signed-off reference experiments were rebuilt successfully after the changes.

v0.5a uses a molten render order of `5`, after the Cosmic signal order of `4`, and reduces the Cosmic above-surface lift to `45%` of its standalone value. Together with full surface binding, this establishes a consistent depth relationship during orbiting without disabling depth testing or forcing far-side lava through nearer terrain.

Several live horizontal orbit angles and a low Monumental angle were inspected after the correction. The information layer remained surface-conformed and did not overtake molten coverage as the camera changed. Communication remained visible where its conduits were not physically covered.

## Visual outcome

The two layers clearly occupy one depression. Persistent circuitry remains visible across the outer territory and down the well; molten streams accumulate around the rim and enter through independently phased releases. Comet-like signal heads remain legible in combined mode at the existing default brightness.

The synthesis also exposes real conflict. Dense molten forms obscure subsidiary circuitry and the shared warm palette can produce local competition. An initial camera-dependent foreground inversion was corrected structurally through full surface conformance, reduced Cosmic lift and explicit molten render precedence; no decorative effect was used.

Elevated provides the most complete diagnostic overview. Monumental gives molten releases greater weight and makes individual motion contrasts more dramatic, while hiding more fine topology behind the foreground.

## Performance

The combined production build succeeds. The default network contains approximately 3,059 nodes, 4,222 connections and 110 active communication events. Browser inspection produced no warnings or errors.

At one extended-run sample with the physical system at its 700-parcel ceiling, the fixed simulation step reported approximately `3.50 ms` and molten reconstruction approximately `4.40 ms`. The scene remained interactive in both camera views and all three layer modes.

## Acceptance assessment

1. **Both systems on one membrane:** passed.
2. **No conceptual rewrite:** passed; narrow composition APIs only.
3. **Physical/gravitational molten behaviour:** passed.
4. **Route-bound constant manifested-speed communication:** passed by retaining v0.4b propagation.
5. **Pit-independent Cosmic topology:** passed.
6. **Three inspection states:** passed without resetting hidden systems.
7. **Interactive usability:** passed in live inspection, with the established physical parcel-cap caveat.
8. **Earlier experiments preserved:** passed; both reference builds succeed.
9. **Review and outcome documentation:** passed.

## Remaining limitations

- The physical default can reach the 700-parcel ceiling during a long high-inflow run.
- Visibility modes do not reduce computation because they intentionally preserve temporal continuity.
- The long dual control surface is suitable for diagnosis, not final presentation.
- Occlusion still requires artistic judgement before layering proceeds; the corrected foreground precedence intentionally allows matter to hide information where coverage is dense.
- This experiment does not establish the throat or the Tree and provides no evidence that either can yet be added successfully.

## Recommendation

Stop for human review as required. The implementation is a faithful enough collision of the two signed-off systems to answer the next artistic question without having pre-answered it through redesign.
