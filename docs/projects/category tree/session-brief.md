# Category Tree — Gate 2 closure and baseline restoration

## Context

Gate 2 — continuous Tree surface — is now concluded as a **failed experiment**.

The experiment produced substantial and useful technical work. It demonstrated
that demanding continuous-surface topology could be achieved for significant
Tree states, including successful manifold and provenance audits.

However, the resulting geometry materially damaged the signed-off visual form
of the Tree. Junction swelling, collars, sockets, wedges and other geometric
artefacts replaced the clean engineered character of the original Tree.

This is unacceptable because this is an artwork as well as an engineering
experiment.

Physical surface continuity is therefore no longer a requirement.

The experiment has nevertheless clarified the artistic direction.

## The Transducer

The Tree is not a botanical tree. It is an engineered, tree-like structure
acting as a transducer between the Universe/Cosmos and the hierarchy it
represents.

The emerging conceptual model is:

- matter/energy flows upward from the gravity well through the trunk and into
  the hierarchy;
- information flows inward/downward from the branches through the hierarchy;
- information converges on the trunk;
- techno-runes on the trunk will eventually participate in its transformation
  or encoding;
- transformed information then enters the communications flows within the
  Cosmos/gravity well.

Connectivity is therefore **semantic and dynamic rather than topological**.

The hierarchy and its authored paths provide the information conduits. The
visible branch meshes do not need to form one continuous manifold.

Do not implement The Transducer in this session.

This session is housekeeping and restoration only.

Before modifying or restoring anything, preserve the complete current workspace
containing the Gate 2 continuous-surface experiment.

`archive/gate-2-continuous-surface`

The branch must preserve the current Gate 2 implementation, tests,
`gate-2-investigation.md`, and other relevant experimental work.

Commit the current state to that branch with a commit message that clearly
identifies it as the abandoned Gate 2 continuous-surface experiment.

Gate 2 is failed as an artistic direction, not worthless work. Do not delete or
discard its history.

## 2. Restore the pre-Gate-2 baseline

Return to the main development branch.

Restore it to the last committed state before Gate 2 continuous-surface work
began.

Do not selectively transplant Gate 2 meshing, worker, topology, fallback or
continuous-surface implementation code into the restored baseline.

Verify that the restored application contains the previous non-continuous Tree.

Verify specifically that:

- the Tree is visible;
- the previous Tree form has returned;
- recursive unfolding operates again;
- Growth tiers operate as before;
- the existing controls remain responsive;
- the application builds and runs normally.

If the correct pre-Gate-2 baseline is ambiguous, inspect Git history and
identify it from evidence rather than guessing.

## 3. Restore the glinting graphite Tree

The restored Tree should not remain in the white visual treatment used during
the geometry studies.

Recover the earlier **glinting graphite** Tree treatment from repository
history.

Do not invent a new graphite material if the previous treatment can be
recovered.

Apply only the changes necessary to restore that earlier graphite appearance.

The artistic reason is important:

> Luminosity will reveal the structure; the structure should not provide the
> luminosity.

The forthcoming information-flow layer will use transient luminosity moving
through the hierarchy. The underlying Tree should therefore be dark, restrained
and metallic/graphitic, with its form primarily revealed by glints, scene
lighting and eventually by information passing through it.

The Tree itself must not become a permanently luminous object.

## 4. Verify the restored baseline

After restoration, verify in the browser that:

- the Tree has the intended glinting graphite appearance;
- its form corresponds to the pre-Gate-2 Tree rather than the continuous-surface
  experiment;
- recursive unfolding is visibly operating;
- the Tree grows through its configured tiers;
- existing controls still work;
- no Gate 2 continuous-surface runtime machinery remains active on the restored
  main branch.

Run only the tests/builds reasonably necessary to verify this restoration.

Do not perform Gate 2 geometry experiments or expensive audit runs.
