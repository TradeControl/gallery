# Superstrate modules

This directory owns reusable metaphysical-superstrate mechanisms, not a page or a Composition adapter.

`emergent-field-layer.js` creates one camera-centred, textureless directional shell. It contains no stars, astronomical objects, textures or scene lights. Translation has no parallax, while camera rotation can reveal a different part of the directional field.

The public **presence**, **breath** and **coherence** parameters describe manifestation rather than astronomical weather. Four causal fields each own a direction, angular reach, procedural morphology, phase and advection vector:

- **substrate** supplies low-frequency depth pressure;
- **physical** condenses a restrained warm source;
- **information** articulates pearlescent order;
- **living** extends a recursively warped reach.

The fifth field, **Confluence**, is not another source. It is derived from the six pairwise products of the four localized fields and therefore cannot manifest when only one source is active. Its control governs how strongly those interactions become visible.

Motion is intrinsic: each field advects and pulses at a different incommensurate rate even when Breath is zero. Breath controls how strongly the local pulses express themselves; only Freeze stops the field.

The standalone study drives source strength with the four magnet sliders and can isolate every source or Confluence for review. `setSource()` and atomic `setSources()` accept normalized directional placement and angular radius. A later Composition adapter can derive those directions from real world positions without changing the field engine. This library does not import, inspect or own the Substrate, Universe, Cosmos, Tree or Composition.

The standalone page owns its camera, renderer, controls and sole animation loop. `index.js` is the public export surface.
