# Casting Pit experiment archive

These runnable studies are preserved as historical steps superseded by the active Universe/Cosmos composition:

- `molten`
- `parcels`
- `ribbons`
- `variable-packets`
- `cosmic-circuitry`
- `well-throat`

The `lib/universe` folder contains the throat-specific membrane and the rejected v0.6d-capable sluice-layer variant required by `well-throat`. They are deliberately isolated from the active shared library.

The standalone early studies were moved without rewriting their source. The archived well-throat imports were adjusted only enough to keep that historical experiment runnable in its new location.
