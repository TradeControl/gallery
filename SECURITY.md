# Security policy

## Supported versions

Security fixes are applied to the current `main` branch and, once releases
exist, to the latest published Gallery release. Historical studies and
archived experiments are retained as research evidence and are not
independently supported applications.

## Reporting a vulnerability

Please do not disclose a suspected vulnerability in a public issue.

Use GitHub's private vulnerability reporting for this repository when it is
available:

https://github.com/TradeControl/gallery/security/advisories/new

If private reporting is unavailable, email `office@tradecontrol.co.uk` with
the subject **Gallery security report**. Include:

- the affected file, page or release;
- steps to reproduce the problem;
- the likely impact; and
- any suggested mitigation.

Please avoid including personal data, credentials or active secrets in the
initial report. Trade Control Ltd will acknowledge a complete report and
coordinate any necessary disclosure after the issue has been assessed.

## Scope

The deployed Gallery is intended to be a static, client-side visual
experience. Reports about source disclosure inherent in a public repository,
unsupported historical studies or artistic behaviour without a security
impact are outside this policy.
